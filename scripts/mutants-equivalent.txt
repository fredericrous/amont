# Mutants no test could tell from the original code (the plan's "equivalent"
# exception), so mutants-check.sh never counts them as lost. One extended
# regex per line, matched against the mutant's description ("delete field x
# from struct Y expression in f"), each under the reason it is equivalent.
# cargo-mutants' own exclude_re does not reach struct-field mutants (27.1.0).

# wait_within drops the silence budgets when nothing watches the output.
# With no Activity, `judge` reads neither (`quiet` and `waiting` are None)
# and the kill message reads `idle_secs` only when `quiet_secs` is Some:
# deleting either field turns a blocking wait into polling, and changes no
# verdict (amont#368).
^delete field (silence|extended) from struct Clocks expression in wait_within$
